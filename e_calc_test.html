Центральный контент (скролл) Нет результатов для function resizeMove(e) { if (!isResizing) return; // Считаем ширину в процентах от окна const newWidthPx = window.innerWidth - e.clientX; const newWidthPercent = (newWidthPx / window.innerWidth) * 100; // Ограничиваем от 15% до 70% if (newWidthPercent > 15 && newWidthPercent 50) { container.style.gridTemplateColumns = `1fr 4px ${newWidthPercent}%`; } } А можо определить минмальный и максимальный проценты определить через переменные css.
Главные особенности Независимая прокрутка: У каждой панели задано overflow-y: auto, поэтому прокручивается только та область, где находится курсор или чей контент больше по высоте.Фиксированный низ: Задана точная высота строки в grid-template-rows (60px или любое ваше значение).Изменение ширины справа: Свойство resize: horizontal включает уголок изменения размера. Использование direction: rtl меняет сторону захвата на левую границу панели (чтобы было удобно тянуть изнутри экрана).
